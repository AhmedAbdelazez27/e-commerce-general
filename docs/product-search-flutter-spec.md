# بحث المنتجات — مواصفات تطبيق Flutter

نفس السلوك المطبّق على الموقع. خانة البحث في شريط التطبيق فقط، ومفيش خانة بحث تانية فوق قائمة المنتجات.

المطابقة بالعربي والإنجليزي، وتطبيع الحروف (الهمزات، ة/ه، ى/ي، التشكيل)، شغلة الباك اند. التطبيق يبعت النص كما كتبه المستخدم بعد `trim` فقط.

`Lang` يكون `ar-EG` أو `en-US` حسب لغة التطبيق.

---

## 1. تنفيذ البحث

البحث يتنفّذ في الحالات دي:

- ضغط زر البحث
- Enter
- اختيار اسم من قائمة الاقتراحات

### الفلاتر والصفحة

- لو المستخدم داخل تصنيف أو أي فلتر (براند، نوع، سعر، مواصفات): البحث يفضل جوّه نفس الفلاتر، والنتيجة ترجع للصفحة الأولى.
- لو البحث من أي شاشة تانية: افتح قائمة المتجر بالنص فقط، من غير فلاتر.
- النص الفاضي يمسح البحث. لو المستخدم لسه داخل تصنيف، التصنيف يفضل.

### جلب المنتجات

`POST /api/services/app/EcPublicCatalog/SearchProducts`

```json
{
  "searchText": "كريم",
  "categoryId": 314,
  "includeChildrenCategories": true,
  "lang": "ar-EG",
  "sortBy": "featured",
  "skipCount": 0,
  "maxResultCount": 20,
  "currencyId": 1,
  "currencyCode": "EGP"
}
```

- ابعت `searchText` فقط لو فيه نص بعد `trim`.
- حجم الصفحة 20. الصفحة الأولى `skipCount = 0`، والصفحة الثانية `skipCount = 20`.
- `includeChildrenCategories` يفضل `true` لما فيه `categoryId`.
- أضف `brandIds` و`productTypeIds` و`minPrice` و`maxPrice` و`specificationFilters` فقط لو المستخدم مختارها.

قيم `sortBy`:

| واجهة الترتيب | sortBy |
| --- | --- |
| المميز | featured |
| السعر من الأقل | price_asc |
| السعر من الأعلى | price_desc |
| الأحدث | newest |
| التقييم | rating |
| الاسم | name_asc |

### فلاتر الجانب

نفس النص ونفس الفلاتر، عشان أعداد الفلاتر تطابق النتائج:

`GET /api/services/app/EcPublicCatalog/GetProductFilters`

```
?SearchText=كريم
&CategoryId=314
&IncludeChildrenCategories=true
&Lang=ar-EG
&CurrencyId=1
&CurrencyCode=EGP
```

## 2. الاقتراحات أثناء الكتابة

قائمة منسدلة تحت خانة البحث. أسماء فقط، وبحد أقصى 10. من غير صورة ولا سعر ولا تصنيف.

`GET /api/services/app/EcPublicCatalog/GetSearchSuggestions`

```
?SearchText=كري
&MaxResultCount=10
&Lang=ar-EG
```

مثال الرد:

```json
{
  "result": {
    "items": [
      {
        "name": "كريم مرطب",
        "nameAr": "كريم مرطب",
        "nameEn": "Moisturizing cream"
      }
    ]
  }
}
```

اسم الصف المعروض:

- العربي: `nameAr`، ولو فاضي `name`، ولو فاضي `nameEn`
- الإنجليزي: `nameEn`، ولو فاضي `name`، ولو فاضي `nameAr`
- تجاهل الاسم الفاضي، ومتكررش نفس الاسم

### متى يتبعت الطلب

- بعد حرفين على الأقل.
- بتأخير 300 مللي ثانية من آخر حرف. متبعتش طلب مع كل حرف.
- أي طلب أقدم يتلغى لما المستخدم يكمّل كتابة.
- أقل من حرفين: اقفل القائمة ومتبعتش طلب.

### شكل القائمة

- أثناء التحميل: مؤشر صغير جوه القائمة فقط. ممنوع لودر على الشاشة كلها.
- لو الرد فاضي أو الطلب فشل: اقفل القائمة من غير رسالة خطأ.
- الضغط على اسم يبحث بالاسم ده ويفتح نتائج المتجر، بنفس قواعد الفلاتر في القسم 1.
- اللمس بره القائمة يقفلها من غير ما يمسح النص.

### لوحة المفاتيح

- السهم لتحت والسهم لفوق يتحركوا بين الأسماء، ويقفوا عند أول وآخر صف.
- Enter على صف محدد يبحث بالاسم ده.
- Enter من غير تحديد يبحث بالنص المكتوب.
- Escape تقفل القائمة من غير ما تمسح النص.

على الموبايل: لمس الصف يساوي اختياره.
